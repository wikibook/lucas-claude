# 스킬

> 책 4장과 연결되는 보충 자료입니다.
> 클로드 스킬은 클로드에게 특정 작업 방식, 지식, 파일 처리 절차를 추가하는 기능입니다.

[← 카탈로그 목차](README.md)

## 스킬을 살펴보는 순서

1. 먼저 공식 문서에서 스킬의 개념과 사용 방식을 확인합니다.
2. [skills.sh](https://www.skills.sh/)에서 분야·인기 순으로 스킬을 검색합니다.
3. 공식·커뮤니티 저장소의 `SKILL.md`를 열어 동작을 확인한 뒤 `npx skills add <owner/repo>`로 설치합니다.
4. 설치 전에는 `SKILL.md`의 권한·외부 호출 범위를 반드시 직접 확인합니다(책 4.2.2절).

## Skills Directory — skills.sh

[skills.sh](https://www.skills.sh/)는 오픈 Agent Skills 생태계의 **검색·리더보드·설치** 포털입니다.
클로드 코드·Cursor·Codex·Windsurf 등 20+ 에이전트에서 같은 스킬을 한 줄로 설치할 수 있습니다.

### 필요한 스킬 골라 설치하기

아래 명령어는 실습할 프로젝트 폴더에서 터미널을 열고 실행합니다. [skills CLI](https://github.com/vercel-labs/skills)를 쓰려면 Node.js 22.20 이상이 필요합니다.
먼저 저장소에 어떤 스킬이 있는지 살펴본 뒤, 필요한 스킬을 골라 설치하세요.

```bash
# 설치하지 않고 스킬 목록만 확인
npx skills add anthropics/skills --list

# skill-creator를 클로드 코드에 설치
npx skills add anthropics/skills --skill skill-creator -a claude-code
```

`--skill`은 설치할 스킬을, `-a claude-code`는 사용할 에이전트를 지정합니다.
기본 설치 범위는 현재 프로젝트입니다. 다른 프로젝트에서도 쓰려면 설치 명령어 끝에 `-g`를 붙이세요.

다른 저장소에서도 같은 방식으로 필요한 스킬을 고를 수 있습니다.

```bash
npx skills add coreyhaines31/marketingskills --skill copywriting cro
npx skills add obra/superpowers --skill brainstorming test-driven-development
npx skills add mattpocock/skills --skill grill-with-docs tdd to-prd
```

### 설치한 스킬 확인·업데이트·제거

설치한 뒤에는 목록에서 스킬 이름을 확인하세요. 아래는 `skill-creator`를 관리하는 예입니다.

```bash
# 현재 프로젝트에 설치한 스킬 확인
npx skills list

# 업데이트가 있는지 확인
npx skills check

# 현재 프로젝트의 skill-creator 업데이트
npx skills update skill-creator -p

# 현재 프로젝트에서 skill-creator 제거
npx skills remove skill-creator
```

`-g`로 설치했다면 `npx skills list -g`로 목록을 확인하고, 업데이트·제거 명령에도 `-g`를 붙이세요. 업데이트할 때는 위 예시의 `-p` 대신 `-g`를 씁니다.
전체 옵션은 [CLI 명령어 안내](https://github.com/vercel-labs/skills/blob/main/docs/commands.md)에서 확인할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 역할 | 스킬 검색, All Time / Trending / Hot 리더보드, 에이전트별 호환 안내 |
| CLI | [vercel-labs/skills](https://github.com/vercel-labs/skills) — `npx skills add`가 skills.sh와 연동 |
| 책 연결 | 4장 탐색·설치, 6·7·8장에 실린 커뮤니티 스킬 설치 |

### Vercel Agent Skills

[Vercel Agent Skills](https://github.com/vercel-labs/agent-skills)는 React·Next.js 성능 개선, 웹 화면 검토, Vercel 배포 등에 쓰는 스킬 모음입니다.
7장에서 만든 포트폴리오나 8장의 시안을 코드로 옮긴 뒤에는 `web-design-guidelines`를 써 보세요. 폼 입력란의 설명, 키보드 조작, 이미지 대체 텍스트 등을 코드에서 점검합니다.

```bash
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a claude-code
```

설치한 뒤에는 "web-design-guidelines 스킬로 이 포트폴리오의 접근성을 점검하고, 수정할 파일과 이유를 알려주세요"처럼 요청하면 됩니다.

### Obsidian Skills

[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)에는 9장의 볼트에 자료를 모으고 정리할 때 쓸 수 있는 스킬이 들어 있습니다.

| 스킬 | 하는 일 | 9장에서 써 볼 곳 |
| --- | --- | --- |
| `obsidian-markdown` | 위키링크, 속성, 콜아웃 등 옵시디언 문법에 맞춰 노트를 작성·수정 | `wiki/` 페이지를 만들고 관련 노트 연결하기 |
| `defuddle` | 웹 페이지에서 메뉴·광고 등을 빼고 본문을 마크다운으로 추출 | 읽을 글을 `sources/`에 모으기 |
| `json-canvas` | 노드와 연결선이 있는 `.canvas` 파일을 작성·수정 | 수집한 자료와 개념 사이의 관계를 캔버스로 정리하기 |

```bash
npx skills add kepano/obsidian-skills --skill obsidian-markdown defuddle json-canvas -a claude-code
```

9장의 볼트 폴더에서 설치하면 됩니다. 예를 들어 "obsidian-markdown 스킬로 이 위키 페이지의 속성과 링크를 점검해주세요"라고 요청해 보세요.
원본 보존과 출처 기록은 [9장의 `CLAUDE.md`](../chapters/ch09-옵시디언으로-나만의-지식-저장소-만들기/예시/CLAUDE.md) 규칙을 따라주세요.
